# INTELIGENS — מאגר תוכן (Content Store)

זהו מאגר ה**תוכן** של אפליקציית Intelligence Composer — הפרדה חדה בין תוכן לכלים.
הקוד של האפליקציה נמצא ב-repo נפרד: `Anat1969/INTELIGENS`.

## מבנה
- `data/index.json` — קטלוג מרכזי של כל הפריטים (לטעינה מהירה)
- `data/library/merges/` — כל מיזוג כקובץ JSON נפרד
- `data/library/profiles/` — כל פרופיל שמולא כקובץ JSON נפרד
- `data/images/` — תמונות "מרחב מחיה" כקובצי PNG

קריאה ציבורית דרך `raw.githubusercontent.com`. כתיבה דרך GitHub REST API עם טוקן אישי.
היסטוריית הקומיטים היא עץ המיזוגים.
